9. POTENTIAL EVIDENCE SIGNALS FOR DEEPGENE
============================================================
The current database contains several fields that
could later contribute to a transparent prioritization
system:

- Clinical significance
- Review status
- Number of submitters
- Expert panel review
- Conflicting classification status
- Phenotype information

These fields should be treated as evidence signals,
not as an automatic disease-causality score.

This analysis does not assign weights or rank variants.

============================================================
10. ANALYSIS SUMMARY
============================================================
Evidence quality was examined using ClinVar review status and submitter information.

Review status provides information about how ClinVar classifications were supported, while NumberSubmitters provides an additional description of the available evidence.

These fields can later be incorporated into a transparent variant-prioritization framework.

No pathogenicity score or ranking is produced by this analysis.
