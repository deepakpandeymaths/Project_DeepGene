9. ANALYSIS SUMMARY
============================================================
The database contains 5381 unique SCN1A variants.
These variants have 10696 genomic representations.
The database contains 10696 ClinVar records.

The genomic representation layer allows the same biological
variant to be represented separately on GRCh37 and GRCh38.

This analysis describes the structure and completeness of
the current SCN1A ClinVar database. It does not assign
pathogenicity or prioritize variants.
